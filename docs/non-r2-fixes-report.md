# 非 R2 审查问题修复报告

## 本批修复结果

本批修复了剩余审查清单中的登录续期、密码边界、评论展示与深层数据读取、页面请求竞态、管理操作反馈、图片选择分页、相册封面清空、自习室日期及定时器等问题。此前已完成的 OAuth 绑定与上传路径安全修复保留。

按要求，R2 下载整文件缓冲、R2 直传图片宽高、桶配置、对象键、历史媒体地址和索引均未调整；未访问真实 R2 存储桶或修改生产数据目录、生产数据库。编辑器上传选择器的修复仅复用已有上传接口和认证恢复逻辑。

## 行为变化

| 项目 | 修复后的行为 | 主要实现位置 |
| --- | --- | --- |
| 登录过期 | fetch、上传和下载共享一次刷新；并发 401 不重复轮换 Cookie，最多重试一次。终止性刷新拒绝同步清空 token 和用户状态；暂时性网络或服务器异常保留可恢复会话；旧请求不能覆盖新登录。 | `blog-frontend/src/api/client.ts`、`stores/auth.ts`、`api/auth.ts` |
| 上传及下载认证 | 图片、文件、图书上传及文章/图书打包请求接入共享认证；保留进度和服务端错误详情。第三方下载地址不附带本站认证，也不会触发本站刷新。 | `api/files.ts`、`api/images.ts`、`utils/download.ts`、后台文章/图书列表 |
| 密码边界 | 注册和重置密码至少 8 个 Unicode 字符、最多 72 个 UTF-8 字节；超限返回 422。登录超长输入返回 401，不截断密码、不抛出 bcrypt 500。注册和重置表单提前提示。 | `blog-backend/app/utils/security.py`、`schemas/auth.py`、`schemas/user.py`；前端 `utils/password.ts` |
| 深层评论读取 | 后端改为迭代处理，固定返回“主评论＋扁平回复”两层。保存原父子关系，返回回复目标元数据；兼容历史深链、孤立记录和循环记录。删除后代也具有循环保护。 | `blog-backend/app/api/v1/comments.py`、`schemas/comment.py` |
| 三条回复折叠 | 每个主评论默认显示前三条回复，其余显示“展开剩余 N 条回复”；可收起。回复数量不受三条限制；发送后自动展开所在讨论串。点击子回复会发送其实际 ID，并显示“回复 @作者”。 | `views/about/AboutComments.vue`；后台 `FriendApplicationsPanel.vue` |
| 页面请求竞态 | 文章、项目、相册只接受当前请求的结果；旧请求的正文、错误、加载状态不会覆盖新页面。关闭相册或卸载组件后，迟到结果不能重新打开详情。 | `views/post/post.vue`、`views/gallery/project.vue`、`views/images/images.vue` |
| 删除失败反馈 | 通用删除及用户、文件、相册、说说等管理操作区分用户取消和真实失败，真实失败显示后端原因。不会在失败后显示成功提示。 | `admin/composables/useAdminTable.ts` 及相关管理页 |
| 图片选择器 | 接入服务端分页、全库文件名搜索和总数；按 ID 保留跨页选择；关闭、重新打开及旧请求有独立状态保护。 | `admin/components/ImagePickerDialog.vue`；后端 `api/v1/images.py` |
| 图片删除保护 | 在原有外键和图书封面检查之外，补查文章封面、URL 背景和视频封面引用；仍在使用时返回 409，并保留记录与文件。 | `blog-backend/app/api/v1/images.py` |
| 相册封面清空 | 省略封面字段表示保持原值，显式 `null` 表示清除指定封面；清除后按既有设计回退相册首图。无效图片 ID 仍被拒绝，不删除图片。 | `api/v1/albums.py`、`services/album.py` |
| 编辑器上传目标 | 每次粘贴、拖拽或选择文件时读取当前本地/R2 选择，复用具备续期能力的图片上传接口。编辑器已销毁时不再插入迟到结果。 | 后台 `PostEditor.vue`、`AboutEditor.vue`；`utils/editorUpload.ts` |
| 自习室及轮播生命周期 | 自习室按本地 04:00 切换逻辑日，历史摘要使用同一日期函数；历史日期不批量重写。清理延迟结算，删除活动任务会停止计时。三个轮播卸载后不再因迟到请求重新创建定时器。 | `utils/studyDate.ts`、自习室、`HistorySummary.vue` 和三个轮播组件 |

前台友链申请复用 `AboutComments`，因此获得相同的回复折叠行为；后台申请讨论也已接入折叠。申请审核、私有字段、跨账户权限、公开状态限制继续保留。
